# 开发任务队列

状态标记：

- `[ ]` 未开始
- `[~]` 进行中
- `[x]` 已完成
- `[!]` 阻塞

每个任务必须在开始前补充或确认验收标准。任务完成后同步更新本文件和 `docs/STATUS.md`。

## M0 技术基线

### [x] M0-01 Qt/VTK 最小应用

目标：建立可运行的 Qt 6 + VTK 9.6 CMake 工程。

范围：

- 根 `CMakeLists.txt`。
- `CMakePresets.json`。
- `src/app/main.cpp`。
- `src/ui/MainWindow.h/.cpp`。
- `src/render/VtkViewportWidget.h/.cpp`。
- 一个基础 `QVTKOpenGLNativeWidget`。
- 菜单栏、工具栏、状态栏、左侧占位面板。

非目标：

- 工程保存。
- OpenFOAM writer。
- 真实网格。
- 复杂菜单。

验收：

- Debug 构建通过。
- 应用启动。
- 三维视口可旋转、平移、缩放。
- 关闭应用无崩溃。
- 不依赖 OpenFOAM。

### [x] M0-02 六面长方体预览

目标：在 VTK 视口中显示六个可独立着色的长方体面。

验收：

- 六个面颜色不同。
- 有清晰边线。
- 有坐标轴。
- 有适配视图入口。
- 面 actor 可通过稳定 FaceId 识别。

### [x] M0-03 构建与部署说明

目标：确认开发构建和运行时依赖可复现。

验收：

- 记录 CMake、Ninja、MinGW、Qt、VTK 的完整命令。
- 记录 PATH 要求。
- 使用干净环境或最小 PATH 验证启动。
- 记录 Release 和 `windeployqt` 初步流程。

### [x] M0-04 初始化版本控制

目标：为持续开发提供可回滚基线。

验收：

- 初始化 Git 仓库。
- `.gitignore` 排除 `build/`、IDE 用户文件和运行生成物。
- 明确 `OpenFOAM-v2206/` 的处理策略。
- 首次提交包含文档、源码骨架和构建配置。
